## API contract

Administrator/session-only `GET /api/firewall` returns `{revision, enabled, rules:[{cidr,label}], client_ip, peer_ip, loopback_always_allowed:true, updated_at, source}`. Initial source is `environment`; saved source is `database`.

Administrator/session-only `PUT /api/firewall` accepts only `{revision,enabled,rules:[{cidr,label}]}` and returns the complete new GET representation. Errors use `{error,code}`: 400 `invalid_policy`; 409 `revision_conflict`; 409 `self_lockout`. Existing 401 authentication and 403 network denials remain. Rules accept individual IPv4/IPv6 addresses or CIDRs. Reject hostnames, URLs, ports, zone IDs, malformed addresses/prefixes and unknown fields. Bound rules to 256 and labels to 120 characters. Normalize rules, including mapped addresses, consistently.
